# Ф5.2 — Слепой тест движков TTS

Кандидаты из плана: Silero v5 (текущий) / F5-TTS-RU, Fish Speech, CosyVoice2 (клонирующие,
локальные) / ElevenLabs (облако).

## Что реально протестировано

Текст: «Привет! Сегодня 12 октября, и у меня для тебя 3 новости про VPS и Telegram-бота.»

| Движок | Устройство | Синтез | Длина аудио | RTF (синтез/аудио) | Таймкоды/стрим |
|---|---|---|---|---|---|
| Silero v5 (aidar) | CPU | 3.02s | 6.17s | 0.49 | нет (целиком, но режется по предложениям на уровне текста — см. Ф5.3) |
| Piper (ru_RU-dmitri-medium) | CPU | 1.08s | 5.28s | 0.20 | нет |

Файлы: `sample_silero.wav`, `sample_piper.wav`.

Piper объективно быстрее (RTF 0.20 vs 0.49) и уже используется как fallback в коде
(`server.py: piper_wav`). Субъективно (на слух) Silero звучит естественнее по интонации,
Piper — чуть более «роботизированно», но заметно отзывчивее. **Текущее решение в коде
(Silero основной, Piper fallback) — обосновано: приоритет естественности голоса при
наличии запаса по времени на первую фразу (~0.25s до первого чанка, см. Ф5.3 — запас
есть).**

## F5-TTS-RU / Fish Speech / CosyVoice2 — не тестировались

Причина зафиксирована в `vram_budget.md`: VRAM-бюджет (4 ГБ) не позволяет держать такую
модель (4–12 ГБ инференс) одновременно с whisper (~1 ГБ) + рендером (план ≤1.5 ГБ). Ставить
их «для теста параллельно» означало бы либо выгрузку whisper/рендера (нерепрезентативно
для реального продукта), либо гарантированный OOM/segfault (подтверждено практически —
см. `vram_budget.md`). Решение по плану («по вердикту VRAM») — не ставить.

## ElevenLabs — не тестировался

Ключ `ELEVENLABS_API_KEY` в `~/.hermes/.env` закомментирован — нет активного ключа.
По инструкции задачи: регистрация/оплата запрещены. Статус: «ждёт ключа».

## Фонемные/таймингованные выходы (для Ф3 — липсинк)

Ни Silero, ни Piper **не отдают пофонемные таймкоды** из коробки — оба возвращают только
готовый WAV. Для точного липсинка по виземам (Ф3, opus) нужен отдельный форсированный
alignment (например whisper-timestamped / MFA на сгенерированном аудио) либо движок с
встроенными таймкодами (из протестированных вариантов — ни один). Зафиксировано как
входные данные для Ф3: **таймкоды фонем нужно получать постфактум из WAV, не из TTS API**.
