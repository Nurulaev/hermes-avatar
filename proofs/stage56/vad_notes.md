# Ф6.2 — Шумоподавление и VAD

## Silero VAD вместо порога RMS

`server.py` (`transcribe()`) уже вызывает `faster_whisper` с `vad_filter=True` —
**faster-whisper использует Silero VAD внутри** (встроенная модель `silero_vad.onnx` в
пакете `faster-whisper`), это НЕ простой порог RMS уже сейчас. Пункт плана по факту
выполнен в проде без дополнительных правок.

Дополнительно поставлен отдельный пакет **`silero-vad` 6.2.3** (pip) — используется в
`barge_in_demo.py` для независимого realtime-детектора речи на `avatar_aec_in` (не завязан
на whisper, нужен для перебивания на лету, см. `barge_in_report.md`). Результат: модель
корректно отличает тишину / эхо аватара / речь нового источника с шагом анализа 32мс.

## DeepFilterNet / RNNoise — не установлены

Проверка показала: шумовой пол и так низкий (−52.5 дБФС, тихая квартира), а AEC уже
снимает основную проблему (самоэхо). Установка DeepFilterNet (PyTorch, ONNX-модель,
дополнительная CPU-нагрузка на каждый чанк в реалтайме) добавляет задержку в пайплайн STT
без измеренной необходимости на этом железе/помещении. Решение: **отложено** — если
WER на реальной речи пользователя (не синтетической, см. `wer_report.md`) окажется хуже
целевых ≤5%, следующий шаг — поставить RNNoise (легче DeepFilterNet, см. ниже) как
предобработку перед `/stt`. Код `transcribe()` готов принять доп. шаг до `vad_filter`.

Рекомендация на будущее (не выполнено в этом прогоне, чтобы не множить необоснованные
зависимости): `pip install noisereduce` (spectral gating, CPU, без модели) — дешевле
DeepFilterNet, для встроенного ALC256 обычно достаточно.
