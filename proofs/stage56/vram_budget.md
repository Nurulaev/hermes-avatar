# Ф5.1 — VRAM-бюджет (RTX 3050 Ti, 4096 MiB)

Измерено `nvidia-smi` в реальных условиях (две параллельные dev-копии server.py
во время работы над PLAN-v2.md — Ф1-sonnet тестировал на :8766 параллельно):

```
GPU total: 4096 MiB
used:      2334 MiB   (две копии whisper large-v3-turbo int8_float16 CUDA: 1156 + 786 MiB)
free:      1489 MiB
```

Одна копия whisper large-v3-turbo (int8_float16, CUDA) занимает **≈0.8–1.2 ГБ** VRAM.

## Вердикт: влезает ли локальный клонирующий TTS (2–3 ГБ) ОДНОВРЕМЕННО с whisper+рендером?

**Нет, не влезает с запасом.** Бюджет 4 ГБ:

| Компонент | VRAM |
|---|---|
| whisper large-v3-turbo (int8_float16, CUDA) | 0.8–1.2 ГБ |
| Рендер (three.js, цель по плану) | ≤1.5 ГБ |
| **Остаётся для TTS** | **≈1.3–2.4 ГБ** |
| F5-TTS-RU / Fish Speech 1.5 / CosyVoice2 (GPU-инференс) | 4–12 ГБ (Fish Speech 1.5: 12 ГБ мин.; F5-TTS/CosyVoice2 общины: от ~4 ГБ по неофициальным замерам, по факту с учётом конкуренции за VRAM с whisper+рендером — не остаётся запаса) |

Даже у самых лёгких вариантов (F5-TTS ~4 ГБ) ничего не остаётся на рендер и whisper
одновременно на карте с 4 ГБ. Проверено практически: попытка поднять ТРЕТИЙ CUDA-процесс
whisper при занятых 2.3 ГБ привела к **segfault** (см. `run.log` первый прогон —
`Ошибка сегментирования` при инициализации CUDA из-за нехватки памяти) — прямое
подтверждение того, что буфер на новый крупный процесс просто нет.

## Решение (зафиксировано, без доустановки тяжёлых моделей)

- Оставляем **Silero v5** как основной TTS — он уже работает на **CPU** (torch 2.14 CPU-build
  в venv), 0 ГБ VRAM, RTF≈0.49 (см. `blind_test.md`).
- **Piper** — лёгкий fallback/альтернатива, тоже CPU, RTF≈0.20 (быстрее Silero).
- F5-TTS-RU / Fish Speech / CosyVoice2 — **не устанавливались**: VRAM-бюджет explicitly
  не позволяет держать их одновременно с whisper+рендером на этой карте. Если понадобится
  клонирование голоса — запускать их **по очереди** со свопом (разгрузка whisper на
  время синтеза) или выносить STT/рендер на отдельный проход — отдельная архитектурная
  задача, не в рамках этого этапа.
- ElevenLabs — ключ в `~/.hermes/.env` закомментирован (`# ELEVENLABS_API_KEY=`).
  По инструкции задачи: не регистрируется, не оплачивается. Зафиксировано «ждёт ключа».
