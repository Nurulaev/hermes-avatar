# Ф6.3 — Wake-word «Гермес»

Пакет **`openwakeword` 0.6.0** установлен в venv проекта (tflite-runtime 2.14, onnxruntime,
scikit-learn и т.п. — зависимости подтянулись).

## Проблема

`openWakeWord` поставляется **без готовой модели под произвольное слово** — только
предобученные англоязычные ("hey jarvis", "alexa", "hey mycroft" и т.п.), скачиваемые
отдельно. Своей модели под «Гермес» (рус.) в комплекте нет и не появится без обучения.

Варианты обучения, которые нашлись:
1. **openwakeword.com/train** — онлайн-тренер (генерирует синтетический датасет, умеет
   инжектить клонированный голос), 20+ языков заявлено. Веб-сервис, требует интерактивной
   сессии пользователя в браузере — не то, что можно сделать headless в этом прогоне.
2. Локальный pipeline обучения (генерация TTS-датасета + дообучение модели) —
   по независимым отчётам сообщества занимает **часы** реального времени (не считая
   настройки), не вписывается в бюджет этой задачи.

## Решение (зафиксировано, не реализовано в коде на этом этапе)

- **Не обучать кастомную модель сейчас** — слишком дорого по времени для разового прогона.
- Практический fallback, который уже отчасти работает «бесплатно»: `STT_PROMPT` в
  `server.py` уже содержит слово «Гермес» как initial_prompt для whisper — это улучшает
  распознавание слова В ОБЫЧНОЙ транскрипции (подтверждено в `wer_report.md`, фраза 0:
  WER=0%, «Гермес» распознан верно), но это НЕ лёгковесный always-on wake-word детектор —
  whisper large-v3-turbo слишком тяжёл, чтобы гонять его непрерывно в фоне только для
  детекции одного слова.
- Рекомендация для следующего этапа: либо (а) пройти онлайн-тренер openwakeword.com/train
  с пользователем за компьютером (5–10 минут интерактива, один раз), либо (б) использовать
  push-to-talk (уже в плане Ф1, хоткей Super+H) как основной способ активации и
  wake-word — как опциональное улучшение, не блокер.

Эта часть пункта 7 **не закрыта полностью** — требует либо участия пользователя
(онлайн-тренер), либо отдельной задачи с бюджетом в часы на локальное обучение.
Создаю follow-up карточку на kanban.
