# WER-отчёт — акустический loopback (Silero TTS -> колонки -> сырой ALC256 вход -> /stt production, whisper large-v3-turbo CUDA)

Примечание: голос эталона синтезирован (Silero), не человеческая речь — оценка качества STT-пайплайна и акустики, не замена реального теста с пользователем. AEC-источник (avatar_aec_in) не использован намеренно: он подавляет этот же сигнал как эхо колонок (см. aec_report.md) — для живой речи пользователя подавления не будет.

Шумовой пол (комната, через AEC-источник): -52.5 dBFS (тихо).

Средний WER: **10.5%** на 10 фразах.
